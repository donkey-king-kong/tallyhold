## Mock gap list before coding

- The current header and toolbar are loose multi-line regions; the mock has one
  compact header bar and one aligned toolbar with segmented range controls,
  icon zoom controls, percentage, and no visible text pan buttons.
- Current lane metadata is one long SVG text line; the mock gives every lane a
  separate header card above its column with title, slug, status, count, and
  since-time.
- Current labels hard-wrap every 20 characters and quiet-report text floats
  below cards; the mock uses compact fitted cards with status, age, and summary
  inside each card and no mid-word breaks.
- Current connectors are direct lines that can overlap; the mock uses one
  visible routed edge per relationship and a shared lane spine with child ticks.
- Current default is All runs and its camera fits all identities; the mock
  defaults to Last 24 hours, excludes older identities from the graph, and
  keeps text at a readable zoom.
- Current activity rows lead with relative and verification jargon; the mock
  uses local absolute time, plain labels, and summaries in compact rows.
- Current inspector leaks the identity-kind fallback and lacks the mock's
  name/status/worktree hierarchy, facts list, full-ID copy row, and Run N of M
  activity heading.
- Current navigator is a flat identity list; the mock groups rows by worktree,
  keeps run counts in their identity rows, and collapses older runs once.
- Current time formatting omits the date outside local today; the mock's date
  policy requires dates throughout intervals, run choices, activity, and footer.
